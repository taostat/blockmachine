**Blockmachine (SN19)** provides decentralized RPC and archive node infrastructure for [Bittensor](https://blockmachine.io/bittensor-rpc) and [Ethereum](https://blockmachine.io/ethereum-rpc). Independent miners compete to serve requests, and every response is checked with Merkle proofs before it reaches the caller.
